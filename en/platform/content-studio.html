Content Studio

Content Studio presents the complete workflow for a piece of content: from creating a project and linking performances to the library, production and assembly of ready-to-publish materials for each channel.

Studio Home Screen

The starting point: select a venue, view projects and enter the relevant working context quickly.

On screen: The home screen shows venue selection, the project list and access to the main work areas.

Start by choosing a project

On the home screen, users choose a venue, view the project list and open an individual event without searching through the whole system.

Project Profile

The event's main record: name, type, genre, short description, full source text and current project status.

On screen: The project profile stores event details, descriptions and the production status.

One project — one content hub for the event

The essential event information is stored here and used later in the library, production and channel workspaces.

Linked Performances

A project can be associated with specific venue performances so that content and copy support actual events on sale rather than abstract concepts.

On screen: This view links the content project to specific performances at the venue.

The project is linked to real performances

Studio shows the venue's available performances and lets users link them to a project, ensuring the correct date, time, venue and sales context are used downstream.

Project Library

Posters, videos, photographs, text and other working materials associated with this project are stored here.

On screen: The library keeps files and creative assets associated with the same content project.

All event assets in one place

The library prevents assets from being scattered among folders and messaging apps: everything needed to assemble content stays within one project.

Production

A workspace for preparing copy, adaptations and materials for different formats and uses.

On screen: The production area gathers copy, content versions and prepared deliverables.

Working versions of content are prepared here

Content Studio does not replace graphic or video editors; it brings together copy, adaptations, intermediate revisions and production outputs for the project.

Channel Workspaces

Final publication assembly for a particular channel: website, Facebook, Instagram, TikTok, YouTube, Telegram, Viber, email or SMS.

On screen: One project supplies channel-specific materials while retaining a common source.

One project — many ready-to-publish outputs

Each channel gets content assembled in its own format, while remaining connected to the same project, materials and event.
